# porfolio

Portfolio personal — SvelteKit + TypeScript + Tailwind CSS.

## Stack

- SvelteKit 2 + Svelte 5
- TypeScript (strict)
- Tailwind CSS 4 (vía `@tailwindcss/vite`)
- Vite

## Arranque

```bash
npm install
npm run dev
```

Abre http://localhost:5173.

## Checks

```bash
npm run check   # svelte-check + tipos
npm run build   # build de producción
```
